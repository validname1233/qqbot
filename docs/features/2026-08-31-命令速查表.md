# 命令速查表

命令以 `/` 开头，群里使用需 @机器人；私聊直接说话、或群里 @机器人 不带命令，会自动当作 /Agent 请求处理。

模型自主办事：需要时自己联网搜索、翻查更早的聊天记忆、记提醒、看图，综合作答。
/Agent [请求]

深度网络调研：多轮搜索、逐页阅读、层层深挖，输出带来源的报告，约 1~3 分钟。
/深度检索 [问题或网址]（/ds）

在 Python 工作台执行任务（读文件、算数据等），需管理员开启；平时 /Agent 会自动委派，此处为手动直达。
/代码 [任务描述]（/code）

一次性倒计时提醒：到点机器人主动来催你，秒数 10~86400。
/定时任务 [秒数] [提醒内容]（/提醒 /remind）

每天固定时刻自动跑一次 /Agent 并把结果推送回来。
/任务 添加 [H:MM] [提示词] ｜ 列表 ｜ 删除 [序号]（/定时提问）

掷骰子：骰数d面数，可带加减修正（如 1d100+20），多骰列出算式。
/r [骰子表达式]（/roll /骰子）

自定义机器人人设：群聊整群生效，单聊个人生效。
/set_personality [人格描述 或 清空]

领取知识库管理页入口，可上传/删除文件（群聊仅群主和管理员，单聊本人；群内检索人人可用）。
/知识库管理（/知识库）

1~100 猜数字：开局后直接发数字，发「退出」结束，全群共用一个谜底。
/猜数字

群内德州扑克（2~8 人）：开桌后发「加入」「开始」，底牌私聊发你，轮到你时发「过牌 / 跟注 / 加注 数字 / 全下 / 弃牌」。
/德州扑克

强制中断本会话正在跑的 /Agent 或 /深度检索。
/stop（/停止）

显示本速查表。
/help（/帮助 /菜单）

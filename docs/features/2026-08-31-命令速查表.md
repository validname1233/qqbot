# 命令速查表

所有命令以 `/` 开头；群里使用需 @机器人。不带 `/` 的消息不会触发命令。

**命令：`/help`**
功能：显示本速查表。

**命令：`/stop`（`/停止`）**
功能：强制中断自己正在跑的 /Agent 或 /深度检索 任务，立即确认。每个会话同时只能跑一个长任务，重复发起会提示先 /stop。

**命令：`/Agent <请求>`**
功能：让模型自主办事——需要时会自己联网搜索、记/删长期记忆、设提醒，综合结果后回答。

**命令：`/深度检索 <问题或网址>`（`/ds`）**
功能：深度网络调研：搜起点 → 逐页阅读 → 顺着链接层层深挖 → 输出带来源的报告。约 1~3 分钟。

**命令：`/定时任务 <秒数> <内容>`（`/提醒` `/remind`）**
功能：倒计时提醒，到点机器人主动来催你。秒数 10~86400。

**命令：`/新闻订阅 开 | 关 | 时间 9:00 | 关键词 科技 财经`（仅群聊）**
功能：每日新闻定时推送到群的开关与配置。

**命令：`/set_personality <人格描述>`**
功能：自定义机器人人设，群聊整群生效、单聊个人生效。

**命令：`/猜数字`**
功能：1~100 猜数字游戏，开局后直接发数字，发「退出」结束。

---
*提示：对机器人说"记住……"“忘掉……”会自动存取长期记忆；发图后用 /Agent 提问可以看图说话。*

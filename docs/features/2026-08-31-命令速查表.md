# 命令速查表

所有命令以 `/` 开头；群里使用需 @机器人。不带 `/` 的消息不会触发命令。

**命令：`/help`（`/帮助` `/菜单`）**
功能：显示本速查表。

**命令：`/stop`（`/停止`）**
功能：强制中断自己正在跑的 /Agent 或 /深度检索 任务，立即确认。每个会话同时只能跑一个长任务，重复发起会提示先 /stop。

**命令：`/Agent <请求>`**
功能：让模型自主办事——需要时会自己联网搜索、打开网页、翻查更早的聊天记忆、记/删长期记忆、设提醒，综合结果后回答。执行中会先推送「正在做什么」的进度消息。

**命令：`/深度检索 <问题或网址>`（`/ds`）**
功能：深度网络调研：搜起点 → 逐页阅读 → 顺着链接层层深挖 → 输出带来源的报告。约 1~3 分钟。

**命令：`/定时任务 <秒数> <内容>`（`/提醒` `/remind`）**
功能：倒计时提醒，到点机器人主动来催你。秒数 10~86400。

**命令：`/任务 添加 H:MM <提示词> | 列表 | 删除 <序号>`（`/定时提问`）**
功能：通用定时任务——存一条提示词，每天固定时刻自动跑一次 /Agent 并把结果推送回来（群聊/单聊均可）。例：`/任务 添加 9:00 搜今天的科技新闻并播报`。

**命令：`/set_personality <人格描述>`（或 `/set_personality 清空`）**
功能：自定义机器人人设，群聊整群生效、单聊个人生效；发「清空」恢复默认人设。

**命令：`/猜数字`**
功能：1~100 猜数字游戏，开局后直接发数字，发「退出」结束。

---
*提示：对机器人说"记住……""忘掉……"会自动存取长期记忆；发图后用 /Agent 提问可以看图说话；问"我们之前聊过什么"时它会自己翻查更早的对话记忆。*

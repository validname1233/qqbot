# QQ 机器人操作手册

> 覆盖全部用户可用功能（命令、会话模式、Agent 工具），基于源码 `src/registry.ts`、`src/session/runner.ts`、`src/agent/tools/`、`src/agent/deep-search/` 盘点。
> 更新日期：2026-08-31（深度检索与搜索 provider 模式已上线）

## 使用总则

- 所有命令以 `/` 开头：`/命令 参数`。不带 `/` 的普通消息不触发任何命令（观察者功能除外）。
- 未知的命令名会回复"未知命令"提示。
- 群聊中通常需要 @机器人 触发事件（`GROUP_AT_MESSAGE_CREATE`）；单聊直接发。
- 配置类功能（新闻订阅、人格）按会话维度隔离：群聊按群共享，单聊按用户独立。

---

## 一、独立命令（直接可用）

### 定时提醒

命令：`/定时任务 <秒数> <提醒内容>`（别名：`/提醒`、`/remind`）
功能：设置一个定时提醒，到点后机器人主动推送一句符合人设的提醒话术。秒数必须是 10~86400（一天）之间的整数。示例：`/定时任务 3600 提醒我一个小时之后去做饭`。设置后立刻收到确认，提醒在未来独立触发。群聊推回群、单聊推给用户。

### 深度检索

命令：`/深度检索 <问题或网址>`（别名：`/ds`、`/deepsearch`）
功能：对一个话题做深度网络调研：先联网搜索拿起点（若参数直接是 `http(s)://` 网址则跳过搜索、从该页开始），然后像浏览器一样逐页阅读、顺着页面链接逐层深挖（可点击翻页/展开等交互），最后汇总成一份带来源链接的结构化调研报告。耗时约 1~3 分钟（有轮次与时间预算上限），返回 Markdown 格式报告并保留人设首尾点缀。与 `/Agent` 的区别：`/Agent` 是快问快答（单轮工具），`/深度检索` 是深调研（多轮浏览）。

### 新闻订阅（仅群聊）

命令：`/新闻订阅 开 | 关 | 时间 <H:MM> | 关键词 <词…>`
功能：按群维度的每日新闻推送开关与调参。`开` 开启（默认每天 9:00、关键词"科技"、5 条）；`关` 关闭；`时间 9:00` 修改推送时刻；`关键词 科技 财经` 修改搜索关键词（空格后整段原样保存）。到点后机器人联网搜新闻、生成播报并附链接列表推送到群。单聊使用会提示"只能在群里用"。

### 自定义人格

命令：`/set_personality <人格描述>`
功能：自定义机器人的人格（角色设定），写入数据库后立即生效，影响日常聊天、Agent 任务收尾、定时提醒等所有带人设的场景；工具判断逻辑不受影响。群聊设置则整群共享，单聊设置只影响该用户自己。示例：`/set_personality 你是一个严肃的学术助手`。暂不支持恢复默认人设。

## 二、会话模式（状态机，开局后锁定会话）

### 猜数字

命令：`/猜数字`（开局）
功能：进入猜数字游戏——机器人心里想一个 1~100 的整数，此后该会话的每条消息都由游戏状态机接管：直接发数字会收到"太大/太小"提示，猜中后公布答案与所用次数并结束；发「退出」中途放弃（会公布答案）。开局后无需再加 `/` 前缀，直到游戏结束。会话按"人"粒度锁定（群里各人各玩各的，互不干扰）。

## 三、Agent 与工具（经 `/Agent` 触发）

### Agent 入口

命令：`/Agent <自然语言请求>`
功能：进入 Agent 链路——模型自主判断是否需要调用工具来完成请求，需要则调用后综合结果作答，不需要则直接回答。空参数返回用法提示。消息自带的图片会被下载入库并转写为文字供模型理解（近期窗口内的历史图片也可被"看见"）。

### Agent 可用工具（模型自主决定调用，用户无需直接操作）

命令：（工具）`search` —— 联网搜索
功能：搜索最新信息，返回标题+链接+摘要。参数：`query`（关键词）、`max_results`（条数，默认 6）、`search_depth`（basic/advanced，advanced 更深入但更耗额度）。底层按 `.env` 的 `SEARCH_PROVIDER` 分发到 Tavily（默认）或阿里云联网搜索，对用户无感。

命令：（工具）`add_memory` —— 记入长期记忆
功能：当用户明确说"记住……""帮我记一下……"时调用，把信息存入该会话的长期记忆库（群聊整群共享、单聊个人独享），供日后对话中检索召回。

命令：（工具）`delete_memory` —— 删除某条记忆
功能：当用户明确表达删除某条记忆时调用（"忘掉……""删除关于……的记忆"），按自然语言描述匹配要删的条目，无需提供 id。群聊中任何成员都可删除群共享记忆。

命令：（工具）`clear_all_memories` —— 清空全部记忆
功能：仅当用户明确表达全量删除意图（包含"所有""全部""清空"字样，如"删除所有记忆"）时调用，清空当前会话的全部长期记忆。删除后主动推送一条变更通知。

命令：（工具）`set_reminder` —— 结构化定时提醒
功能：与 `/定时任务` 命令同一份核心逻辑的 Agent 通道——当用户以自然语言表达提醒需求（"一小时后提醒我做饭"）时，模型自动换算秒数并调用。秒数与内容校验规则同 `/定时任务`。

### 深度检索内部工具（仅深检流程使用，日常 /Agent 不可见）

命令：（工具）`open_page` —— 静态阅读网页
功能：抓取网页并返回标题、正文摘要与编号链接列表；跟进链接可传编号（link）或完整地址（url）。静态快速路径，不启动浏览器。

命令：（工具）`interact_page` —— 动态交互网页
功能：用无头浏览器打开页面并执行点击/输入/滚动/截图动作，处理需要 JS 渲染或按钮交互（翻页、展开、搜索框）的场景，返回动作后的页面内容，格式与 open_page 一致。

## 四、后台功能（无需命令，自动运行）

### 记忆落库（观察者）

命令：无（每条消息自动执行）
功能：观察者模式静默运行——收到的每条消息自动写入短期记忆（供上下文对话）并下载消息附带的图片入图片池（供 `/Agent` 触发时懒加载识图）。对用户完全无感，出错也不影响消息处理。

### 每日新闻定时推送

命令：无（由 `/新闻订阅` 的配置驱动）
功能：node-cron 定时任务，按各群订阅配置在设定时刻自动搜索、生成、推送新闻。进程重启后自动从数据库恢复所有已开启的订阅。
